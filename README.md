# 🚀 Indian Multilingual TTS & STT Aided Neural Transceiver

> **Team Chai Samosa** | Smart India Hackathon 2026 Prototype Submission

## 📌 Overview
A functional software prototype developed for the Smart India Hackathon (SIH) 2026. This project tackles **SIH26173** - **Indian Multilingual TTS & STT Aided Neural Transceiver Radio Access for low bitrate links**. Our solution focuses on practical problem-solving, utilizing efficient core logic to deliver a reliable AI-driven application.

## 💻 Tech Stack
* **Core Language:** Python, HTML, CSS and JS
* **Libraries/Frameworks:** SpeechRecognition, gTTS / pyttsx3, Neural Network basics
* **Development Environment:** VS Code
* **Version Control & Collaboration:** Git & GitHub

## ✨ Key Features
* **Multilingual Data Handling:** Engineered core logic to process and route Multilingual TTS (Text-to-Speech) & STT (Speech-to-Text) data streams efficiently.
* **Low Bitrate Optimization:** Implemented optimized logic in Python to simulate data compression and handle low-bandwidth radio link constraints.
* **Robust Transceiver Simulation:** A lightweight, memory-efficient application to simulate the neural transceiver's operational flow without latency.

## ⚙️ How to Run Locally

Follow these steps to set up and run the project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone
https://github.com/Vansh3105-coder/SIH_2026.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd SIH_2026
   ```

3. **Install required dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the application:**
   ```bash
   python main.py
   ```
