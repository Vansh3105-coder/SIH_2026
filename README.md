# 🚀 Indian Multilingual TTS & STT Aided Neural Transceiver

> **Team Chai Samosa** | Smart India Hackathon 2026 Prototype Submission

## 📌 Overview
A functional software prototype developed for the Smart India Hackathon (SIH) 2026. This project tackles **SIH26173** - **Indian Multilingual TTS & STT Aided Neural Transceiver Radio Access for low bitrate links**. Our solution focuses on practical problem-solving, utilizing efficient core logic and data structures to deliver a reliable console-based application.

## 💻 Tech Stack
* **Core Language:** C / C++
* **Development Environment:** VS Code
* **Version Control & Collaboration:** Git & GitHub

## ✨ Key Features
* **Multilingual Data Handling:** Engineered core logic to process and route Multilingual TTS (Text-to-Speech) & STT (Speech-to-Text) data streams efficiently.
* **Low Bitrate Optimization:** Implemented optimized data structures in C/C++ to simulate data compression and handle low-bandwidth radio link constraints.
* **Robust Transceiver Simulation:** A lightweight, memory-efficient console application to simulate the neural transceiver's operational flow without latency.

## ⚙️ How to Run Locally

Follow these steps to compile and run the project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Vansh3105-coder/SIH_2026.git](https://github.com/Vansh3105-coder/SIH_2026.git)
   ```

2. **Navigate to the project directory:**
   ```bash
   cd SIH_2026
   ```

3. **Compile the code:**
   ```bash
   # If using C++
   g++ main.cpp -o app

   # If using C
   gcc main.c -o app
   ```

4. **Run the executable:**
   ```bash
   ./app
   ```
